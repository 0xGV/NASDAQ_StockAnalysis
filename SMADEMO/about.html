About

Project Description

The goal of this project was to create a tool for analyzing the stock market. The goal was to include the ability to not only check the price of stocks across stock exchanges, but also to facilitate the use of technical analysis tools to allow users to analyze the markets using their own judgement. In addition, the StockPicker element was built to help identify strong or weak stocks. The hope is to further the algorithm with machine learning or artificial intelligence to provide better analysis of stocks and the market itself.

This project was written for the ASU Capstone I and II classes.
